# 创意设计部作品集网站 · 部署与接入说明

交付日期：2026-10-14。此包为已确认的正式版本，供free-bbs总网站负责人部署和添加跳转入口。

## 1. 最简接入方式

1. 将本包 `site/` 内的全部文件和 `assets/` 文件夹，上传到总网站服务器的一个独立目录，例如网站根目录下的 `creative-design/`。

2. 确认通过总网站域名下的 `/creative-design/index.html` 可以打开首页。

3. 在总网站菜单、按钮或部门介绍中新增“创意设计部”入口，链接到 `/creative-design/index.html`。

目录名 `creative-design` 仅为示例，可由负责人决定；若使用其他目录，请相应修改总网站入口链接。网站内部已使用相对路径，保持目录结构即可。

不需要继续依赖之前的 ChatGPT Sites 预览地址；访问条件取决于总网站的实际部署网络和访问权限。

## 2. 总网站入口代码

同窗口跳转：

```html
<a href="/creative-design/index.html">创意设计部</a>
```

新窗口打开：

```html
<a href="/creative-design/index.html" target="_blank" rel="noopener noreferrer">
  创意设计部
</a>
```

如果总网站通过后台维护导航，新增菜单项，将地址填为实际部署后的页面地址即可。若独立部署到另一个域名，则将 `href` 替换为该站点的完整 HTTPS 地址。

这是完整的独立网站，请通过链接跳转接入；无需把页面内容粘贴进总网站模板。这样可避免总网站的样式影响作品集排版。

## 3. 文件结构

```text
创意设计部网站-交接包/
├─ readme.md                 本说明，无需放入公开网站
└─ site/                     上传此文件夹内的全部内容
   ├─ index.html             主页／总网站入口目标
   ├─ about.html             部门介绍
   ├─ artwork.html           四个作品分类入口
   ├─ contact.html           联系方式
   ├─ festival.html          学生节
   ├─ welcome.html           迎新季（含无字衫）
   ├─ practice.html          实践周边
   ├─ creative.html          创意项目
   ├─ style.css              页面样式、字体和动画
   ├─ page-effects.js        页面切换效果及配色相关逻辑
   ├─ gallery-layout.js      图片错落排版
   ├─ gallery.js             作品大图浏览
   └─ assets/                背景、标题、logo、作品、照片、字体
      ├─ collections/        四个分类的作品和分类图标
      ├─ photos/             部门合照
      └─ fonts/              本地字体及其许可文件
```

包内包含正式页面所引用的资源；不包含历史对比页面、Git 记录、托管平台配置、开发工具和设计原稿。样式表仍引用的备用图片一并保留，避免遗漏依赖。原始设计素材由部门另行保存，包内图片用于网页展示，不作为印刷原稿。

## 4. 部署要求

* 纯静态 HTML、CSS、JavaScript 网站，不需要 Node.js、npm、数据库或构建命令，也不需要账号、API 密钥。

* 可由已有网站服务器直接提供静态文件服务。将 `index.html` 设为目录首页，或始终使用含 `index.html` 的完整入口链接。

* 保留所有文件名、大小写和文件夹层级。图片文件名含中文、空格，页面中的 URL 已编码；解压和上传时应保留 UTF-8 文件名，不要批量重命名。

* 服务器需正确返回 HTML、CSS、JavaScript、图片、OTF 和 TTF 字体资源。CSS/JS 请求不能被总网站的登录页、404 页面或单页应用路由替换。

* 总网站若使用 React、Vue 等前端路由，请把此子目录配置为静态目录，避免将其中的请求重写到总网站首页。

* 页面含内联脚本、内联样式及动态排版。若总网站配置了严格的内容安全策略（CSP），请负责人检查浏览器拦截记录并配置兼容规则。

* 字体、图片和脚本均随包提供，页面渲染不依赖外部字体库或第三方 CDN。学生节四篇微信推送为外部链接；邮箱链接会调用访客设备的邮件程序。

* 本站首页链接指向作品集自己的首页。如需增加“返回总网站”入口，可在部署后按实际总网站地址另行添加。

## 6. 上线后检查

1. 从总网站实际入口打开作品集，确认地址是服务器 URL，而非本地文件地址。

2. 依次打开 About、Artwork、Contact 及四个作品分类；直接访问子页面 URL 并刷新，确认不会返回 404 或总网站首页。

3. 检查主页背景、其他页面弥散背景、标题、字体、合照及作品是否完整加载。

4. 点击作品查看大图并切换、关闭，检查四篇微信推送和邮箱链接。

5. 在手机和电脑上各查看一次；关闭 VPN 后用校园网和手机移动网络检查实际访问情况。若总网站仅限校园内网，则此子目录也会受到相同限制。

6. 更新文件后如仍显示旧版，请刷新浏览器，并按总网站实际配置清理服务器或 CDN 缓存。

交付前已检查正式页面的本地文件引用并核对拷贝一致性；实际服务器配置和国内网络访问应在部署后按以上步骤验收。

## 7. 查看和维护

本地查看时，可先解压，再双击 `site/index.html`；上线验收请以服务器访问效果为准。不要在压缩包内直接打开网页。

页面文字可在对应 HTML 中修改；样式位于 `style.css`；图片位于 `assets/`。更换图片且保持原文件名时，无需修改引用。新增或改名时，请同时更新 HTML 中的图片地址和大图链接。

思源宋体的官方许可文本随包放在 `site/assets/fonts/LICENSE-SourceHanSerif.txt`，分发字体时请保留。官方来源：<https://github.com/adobe-fonts/source-han-serif> 。Georgia 等系统后备字体未随包分发。
